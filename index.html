SIP — Session Initiation Protocol; sets up, changes, and ends calls.
SDP — Session Description Protocol; describes the audio/video being offered.
RTP / RTCP — the actual media stream, and its quality-report companion.
UAC / UAS — the calling / answering device (User Agent Client / Server).
Proxy / SBC — a server that routes SIP messages between endpoints.
Dialog — the ongoing relationship between two endpoints for one call.
CSeq — a per-dialog counter that keeps requests and responses in order.
Call-ID — a unique ID shared by every message that belongs to one call.
100rel / PRACK — makes provisional responses (like ringing) reliable.
Diversion header — tells the receiving phone a call was forwarded, and why.
